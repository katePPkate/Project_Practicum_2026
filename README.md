# Пространственное распределение региональных показателей на сетке 1×1 км

## О проекте

Решение кейса АНО «ИКИИГУ» по пространственному разнесению агрегированных региональных статистических данных на регулярную сетку 1×1 км с использованием внешних пространственных признаков из открытых источников (OpenStreetMap).

**Цель:** Предложить и реализовать воспроизводимый способ разнесения агрегированных региональных показателей по территории субъекта РФ на регулярной сетке с минимальным размером пикселя 1×1 км — без простого равномерного усреднения, с опорой на внешние пространственные признаки.

## Файлы проекта

- `Project_Practicum_2026.ipynb` — основной Jupyter Notebook с кодом (итоговая визуализация и сравнение методов)

## Методы расчета коэффициентов

### 1. Частотный анализ (baseline метод)
- Загрузка данных OSM из PBF-файла (точки, линии, полигоны)
- Построение сетки 1×1 км внутри границы субъекта
- Агрегация объектов по ячейкам
- Частотный анализ — расчёт веса каждого типа объекта:
  `вес_типа = 1 / (частота_встречаемости + 0.01)`
  Чем реже объект, тем выше его вес.
- Расчёт веса ячейки — взвешенная сумма всех объектов:
  `вес_ячейки = Σ(вес_типа × log(количество + 1))`
- Базовый вес для пустых ячеек — 20% от минимального веса непустой ячейки
- Нормализация — сумма всех коэффициентов = 1

### 2. Пространственное сглаживание
- Для учёта влияния соседей реализована функция усреднения весов в заданном радиусе (по умолчанию 2 км)
- Каждая ячейка получает вес, равный среднему весу всех соседей в радиусе

### 3. Регрессионная модель (машинное обучение)
- Подготовка признаков: анализ типов объектов OSM для всех регионов РФ
- Обучение линейной регрессии на региональных статистических данных
- Модель предсказывает значимость каждого типа объекта для распределения показателей
- Применение обученных весов к ячейкам текущего субъекта
- Все коэффициенты положительные, с усиленной дифференциацией
- Высокая точность модели: R² = 0.987

### 4. Равномерное распределение (baseline)
- Каждая ячейка получает равный вес = 1 / общее_количество_ячеек
- Используется для сравнения эффективности других методов

## Оценка качества

Сравнение методов по:
- Визуальной дифференциации
- Статистическим характеристикам (стандартное отклонение, коэффициент вариации)
- Соответствию ожидаемому пространственному распределению
- Коэффициенту дифференциации (максимум/среднее)

## Ограничения метода

- Данные OSM могут быть неполными для малонаселённых территорий
- Редкие объекты не всегда значимы (например, заброшенное здание)
- Не учитываются социально-экономические факторы напрямую
- Метод не калиброван под конкретные показатели
- Регрессионная модель обучена на ограниченном наборе данных (85 регионов)

## Направления развития
