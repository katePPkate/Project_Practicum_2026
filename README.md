# Пространственное распределение региональных показателей на сетке 1×1 км

## О проекте

Решение кейса АНО «ИКИИГУ» по пространственному разнесению агрегированных региональных статистических данных на регулярную сетку 1×1 км с использованием внешних пространственных признаков из открытых источников (OpenStreetMap).

**Основная идея:** вместо равномерного распределения показателя по площади региона, веса ячеек рассчитываются на основе частотного анализа объектов OSM — редкие объекты получают больший вес, что позволяет учесть пространственную неоднородность.

## Файлы проекта

- `Project_Practicum_2026.ipynb` — основной Jupyter Notebook с кодом
- `map_parsing.py` — вспомогательные функции для загрузки и обработки OSM-данных
- `sources/` — исходные данные (GeoJSON с границами и PBF с OSM, скачаны с geo2day.com)
- `result/` — результаты работы: CSV с коэффициентами для каждой ячейки, карты распределения
- `customer_details/` — данные от заказчика (региональная статистика)

## Метод распределения

1. Загрузка данных OSM из PBF-файла (точки, линии, полигоны)

2. Построение сетки 1×1 км внутри границы субъекта

3. Агрегация объектов по ячейкам

4. Частотный анализ — расчёт веса каждого типа объекта:

`вес_типа = 1 / (частота_встречаемости + 0.01)`

Чем реже объект, тем выше его вес.

5. Расчёт веса ячейки — взвешенная сумма всех объектов:

`вес_ячейки = Σ(вес_типа × log(количество + 1))`

6. Базовый вес для пустых ячеек — 20% от минимального веса непустой ячейки

7. Нормализация — сумма всех коэффициентов = 1

## Пространственное сглаживание (опционально)

Для учёта влияния соседей реализована функция усреднения весов в заданном радиусе (по умолчанию 2 км).

## Результаты

Для каждого субъекта создаются:

`result/{name}.csv` — таблица с ячейками, координатами и коэффициентами

`result/{name}.png` — карта распределения

`result/{name}_avg.png` — карта распределения с учётом соседей


## Ограничения метода

- Данные OSM могут быть неполными для малонаселённых территорий

- Редкие объекты не всегда значимы (например, заброшенное здание)

- Не учитываются социально-экономические факторы

- Метод не калиброван под конкретные показатели

## Направления развития
- Калибровка весов под конкретные показатели (бюджет, население)

- Добавление спутниковых данных (ночная засветка)

- Валидация на муниципальном уровне

- Масштабирование на все субъекты РФ
